O que é este painel

Farm de horas: mantém contas Steam logadas "jogando" os jogos que você configurar, 24/7.

Tempo real: status, tempo farmado e jogos ativos de cada conta atualizam sozinhos na tela.

Webhooks: avisa Discord/Telegram/WhatsApp/SAGE quando algo acontece, e também recebe eventos de outros apps.

Perfil Steam: mostra os dados públicos da conta (nível, avatar, jogo atual etc.) direto no painel.

Steam Web API

Necessária para carregar a "Página de perfil" (nível, avatar, jogo atual etc.). Gere a sua gratuitamente em steamcommunity.com/dev/apikey.

Bans (VAC/Game Ban) & Faceit

Consulta pública da Steam: VAC Ban, Game Ban (inclui bans do Overwatch/anti-cheat do CS2), Community Ban e Economy Ban.

Para contas com CS2 (AppID 730) entre os jogos, também mostra se existe conta Faceit vinculada (nível/elo).

A Steam não libera publicamente dado de "GC ban"/trust factor pra terceiros — só o que aparece acima.

Faceit API Key

Necessária só pra checar Faceit. Crie um app em developers.faceit.com e cole aqui a "Server-side API key".

API pessoal

O que é: um jeito de você (ou um bot seu) consultar em JSON só as SUAS contas Steam e os SEUS logs — nunca os de outros usuários.

Segurança: todo endpoint exige o token abaixo — sem ele, ninguém acessa nada. A senha das contas Steam nunca é exposta pela API.

Seu token de API

Use este token em ?token=, no header X-API-Token ou em Authorization: Bearer.

Exportar configurações

Baixa um arquivo .json com todas as contas e webhooks cadastrados — use como backup ou pra levar pra outro painel.

Importar configurações

Selecione um arquivo .json no formato abaixo. Contas e webhooks já existentes (mesmo usuário) são ignorados.

Formato esperado do arquivo .json

username e password são o login e senha da Steam, exatamente como usados pra entrar no cliente Steam. games é uma lista de AppIDs (números). Em webhooks, url/extra mudam de sentido conforme o type (veja a aba Webhooks: Telegram usa token do bot + chat id, WhatsApp usa número + apikey). 

{
  "accounts": [
    { "username": "meuLoginSteam", "password": "minhaSenhaSteam", "games": [730, 570] }
  ],
  "webhooks": [
    { "name": "Meu Discord", "type": "discord", "url": "https://discord.com/api/webhooks/..." },
    { "name": "Meu Telegram", "type": "telegram", "url": "TOKEN_DO_BOT", "extra": "CHAT_ID" }
  ]
}
